# SYZYGY Component Index

- `syzygy/bootstrap.py` — reproducible environment provisioning and validation.
- `syzygy/identity.py` — agent identity, credentials, permissions, revocation.
- `syzygy/memory.py` — ROM/RAM/CACHE/ARCHIVE memory packages.
- `syzygy/layers.py` — dependency-aware milestone graph and layer states.
- `syzygy/audit.py` — receipt ledger and hash-chain evidence tracking.
- `syzygy/sessions.py` — session lifecycles, checkpointing, handoff records.
- `syzygy/federation.py` — agent peer discovery and knowledge/skill publication.
- `tests/` — bootstrap and validation tests.
